# Admin/User Management — Production Security Contract

## Roles

### Super Admin
Can:
- Create Admin accounts.
- Create Member accounts.
- Edit user information.
- Review/approve/reject password-reset requests.
- Disable/enable accounts.
- View user-management audit records.

### Admin
Can:
- Create Member accounts.
- Manage members according to delegated permissions.
- Cannot create Admin accounts.
- Cannot promote a Member to Admin.
- Cannot approve password-reset requests.
- Cannot edit privileged security fields.

### Member
Cannot create users or change roles.

## Password reset flow

1. User submits a forgot-password request.
2. Request enters `password_reset_requests` with `pending`.
3. Only Super Admin reviews it.
4. When approved, the server resets the account to the configured temporary password.
5. The account receives `force_password_change=true`.
6. On the next successful login, the application MUST redirect to the Change Password screen.
7. The user cannot access the normal dashboard until the password is changed.
8. The new password is checked against password history.
9. A previously used password MUST be rejected.
10. After a successful change, `force_password_change=false` and the temporary password is invalidated.

## Important security note

The requested default password `123456` is extremely weak. If the business requirement mandates it, it must be treated as a one-time temporary credential only, never as a permanent password. Prefer a randomly generated temporary password or a password-reset link in production.

Never store plaintext passwords or password history. Supabase Auth should manage password hashes. The `password_history` table should contain secure hashes generated by the server-side password-history mechanism, not plaintext values.

## Server boundary

All operations involving:
- creating Auth users
- setting temporary passwords
- changing privileged profile fields
- approving resets
- writing password history

must run server-side using the appropriate privileged API. Never expose a Supabase service-role key in browser JavaScript.
